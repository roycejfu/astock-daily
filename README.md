## 目录结构

```
├── index.html          # 首页（自动生成历史列表）
├── latest.html         # 最新一期
├── archive/            # 历史归档 YYYY-MM-DD.html
├── meta.txt            # 报告元数据（日期|趋势|摘要）
└── publish.py          # 发布脚本
```

## 发布脚本用法

```bash
# 发布新报告
python3 publish.py --report /path/to/收盘总结_2026-08-11.html \
                   --date 2026-08-11 \
                   --title "CPO 反弹修复，FCC 禁令暂缓" \
                   --trend up

# 仅重建首页索引（archive 目录变动后）
python3 publish.py --rebuild

# 本地预览，不推送
python3 publish.py --report xxx.html --no-push
```

参数说明：
- `--trend`：`up`(主线走强) / `down`(主线杀跌) / `mixed`(分化震荡)
- `--title`：一句话摘要，显示在首页列表
