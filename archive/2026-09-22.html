📌 归因起手式：先把当日催化剂列全并归类，再看哪些标的挂得上。挂不上的那些，跌的原因就是「挂不上」。

当日催化剂清单（5 条独立线索，不合成一个故事）
① Meta Muse 引爆 CPU 重估：美股 Meta +11.43%（2025 年 4 月来最大单日涨幅）；Muse 上线约 10 天登顶美国 App Store 免费榜、超过 ChatGPT。AMD 把 2030 年服务器 CPU 市场规模从 1200 亿美元上调至 2200 亿美元；英特尔称当前仅能满足约 50% 客户需求。华泰电子口径：Agent = LLM + Planning + Tool Use + Memory，CPU 承担任务编排、数据调度、沙箱执行、记忆管理。
② 费半 +4.29%，但涨幅由 CPU/SoC 贡献：ARM +17.16%、英特尔 +12.14%、AMD +9.95%（市值首破万亿）、高通 +9.29%；而 GPU / AI 互联一侧明显落后：英伟达 +2.30%、博通 +1.60%、台积电 +2.42%、美光 +2.77%。
③ 存储涨价加速（已发生的事实，不是预期）：DDR5 价格加速上涨；苹果已接受三星 2027 年一季度存储芯片报价，较今年三季度上涨 30%~40%；三星 / SK海力士 / 美光 2027 年 DRAM 及 HBM 产能已基本分配完毕，客户实际可获配额约为申请量的六至七成；长鑫科技第五代工艺技术平台实现量产。
④ 国产算力（当日国内事件）：华为昇腾 960 超节点进展超预期（960DT 于 2027Q1 推出、提前三个季度）；阿里云栖大会吴泳铭称 2032 年阿里云全球数据中心规模超 20GW，平头哥发布真武 V900（算力为 M890 的 3 倍）。
⑤ 油价重挫 + 政策：WTI -4.51% 报 95.78、布伦特 -3.40% 报 100.34；国家新闻出版署印发《出版业发展"十五五"规划》（人工智能赋能出版）；发改委称"十五五"北斗产业规模超 1 万亿。

把这张清单往自选股上套，结果极其干净：挂得上 ②③④ 的四只全涨，挂不上的全跌。

挂得上的（上涨）
· 存储三只：澜起 +5.58%、兆易 +2.65%、长鑫 +1.72% —— 直接对应 ③ 存储涨价。兆易当日主力 +19.32 亿（财联社盯盘口径早盘净买入超 22 亿、居全市场首位）。
· 深南电路 +1.26%（主力 +2.44 亿）—— 挂上 ④ 国产算力。深南的载板与服务器 / 通信板更多对应国产算力与交换机，而非北美 AI 加速卡。
· 芯碁微装 +1.13%（主力 +0.28 亿）—— 挂上设备端的"先进制程 + 先进封测设备新需求"。

挂不上的（下跌）—— 跌的原因就是「挂不上」
· 中际旭创 -1.41%（主力 -9.97 亿）：光模块纯挂英伟达 / AI 互联链，而 ② 里涨的是 CPU/SoC（英伟达只有 +2.30%），① 是 CPU 不是光互联。
· 胜宏科技 -2.38%：高端 HDI / 正交背板同样是北美加速卡链，与 ① 的 CPU 重估不在一条线上。
· 盛合晶微 -3.12%（主力 -1.52 亿）：晶圆级先进封装跟随 GPU / HBM 大芯片需求，同样挂不上 CPU 与国产算力。
→ 今天不是"外围利好没传导"，而是"传导了，但只传导到美股涨的那一段"。

⚠️ 这是第四种范式，不是 8/28 型，也不是 9/14 / 9/15 型。前三种都建立在「A 股与外围方向相反」的前提上；今天方向其实一致，错位发生在结构层——A 股复制的不是"费半 +4.29%"这个总数，而是费半内部「CPU/SoC 领涨、GPU/AI 互联落后」这个结构。

⛔ 纪律边界：「通信链退潮」推不出「传媒 / 计算机会持续涨」，只能推出「它们不再被虹吸」。反过来看更要紧——通信链 10 日累计仍有 +42~+55 亿的厚度，累计流入不是安全垫，是获利盘的计量器。

⚠️ 必须点破：今天宽度是恶化的，不是改善的。
· 涨 2374 / 跌 3030 / 平 163（腾讯财经收盘口径）；而午间收盘还是涨 2883 / 跌 2475 —— 半天之内从涨多跌少翻成跌多涨少。

→ 放量 + 宽度恶化 + 上影线 = 高位换手，不是增量入场。9/21 我写"钱没走只是换了地方"，今天这个表述要打折：钱还在场内，但持币的那部分明显变多了。

方向内部的分歧，必须讲出催化剂口径的差异；讲不出，就是归因不完整：

· PCB 内部：胜宏 -2.38% vs 深南 +1.26%。差异在客户结构——胜宏的高端 HDI / 正交背板对应北美 AI 加速卡（GPU 链），深南的载板与服务器 / 通信板更多对应国产算力与交换机（昇腾 960 / 云栖 20GW 这条线）。今天涨的是后者。注意胜宏资金仍是 +1.81 亿而价格在跌——价跌钱进，是有人在接，不是被砸盘。
· 先进封装内部：盛合晶微 -3.12%（主力 -1.52 亿）vs 芯碁微装 +1.13%（主力 +0.28 亿）。差异在环节——盛合是晶圆级封装制造（跟随 GPU / HBM 大芯片订单），芯碁是直写光刻设备（跟随国产先进制程与封测产能扩张的设备招标）。今天钱买的是设备端，不是制造端。
· 存储内部：澜起 +5.58% 涨得最多，却是唯一主力净流出的（-4.42 亿）。这个背离单独放到第 7 段的澜起专项展开。
· 恒生科技内部：腾讯 +4.79% vs 美团 -1.22%，α 差 6.01pp。差异在能不能挂上"AI 应用变现"——腾讯有 Agent 分发入口与广告变现路径，美团挂不上。
